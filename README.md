# 🏎️ WRXpedia
**The Ultimate Subaru WRX & STI Technical & Performance Encyclopedia**

---

## 🌟 Key Features

### 🚘 Complete Subaru WRX / STI Generations Database
- **Exhaustive Generation Coverage**: Detailed technical profiles for all 7 legendary generations:
  - **Meaneye / Classic (GC8 / GF8)** (1992 - 2000)
  - **Bugeye (GD / GG Phase 1)** (2001 - 2002)
  - **Blobeye (GD / GG Facelift 1)** (2003 - 2005)
  - **Hawkeye (GD / GG Facelift 2)** (2006 - 2007)
  - **Stinkeye (Hatchback GR/GH & Sedan GV/GE)** (2008 - 2014)
  - **Raptor Eye / VA** (2015 - 2021)
  - **VB** (2022 - Present)
- **Deep Technical Specifications**: Engine codes (EJ205, EJ207, EJ255, EJ257, FA20DIT, FA24F), stock turbo models, boost pressure, transmission ratios, and drivetrain layouts.
- **Variant Matrix**: Instant tabbed switching between **WRX**, **STI**, and **Special Editions** (22B STI, S202, S204, RB320, R205, S209, Type RA, etc.).

### 🛠️ Quick Tools & Mechanical Specs
- **Torque Specs Database**: Fast reference for critical bolt torque specs (Cylinder head, Wheel nuts, Oil drain plug, Spark plugs, Flywheel, Calipers) in both **Nm** and **ft-lbs**.
- **Fluid Capacities & Viscosity Guide**: Engine oil capacities, gearbox fluids, rear diff oils, coolant, and recommended viscosities (Motul 300V, Subaru Extra S, etc.).
- **Paint Color Codes**: Official Subaru paint code database (02C World Rally Blue, 555 State Blue, K7X WR Blue II, 51E Aspen White, 47A Obsidian Black, etc.) with color preview swatches.
- **Special Editions Catalog**: Production counts, unique upgrades, and collector details.

### 🎨 Auto Analytics Inspired Design System
- **Motorsport Theme**: Deep carbon slate background (`#0B0F19`) with iconic **World Rally Blue** (`#1D4ED8`) and **STI Cherry Blossom Pink** (`#E11D48`) accents.
- **Single-Column Responsive Cards**: Compact 1-card-per-row layout with left thumbnail images, years badges, and chassis code tags.
- **Zero Vertical Text Wrapping**: Robust layout constraints ensuring text never wraps vertically regardless of font scaling or long chassis strings.
- **Developer Footer**: Integrated developer credit with clickable hyperlink to **[dariusdevworks.com](https://dariusdevworks.com)**.
